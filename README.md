# Gaza-Dijkstra

## 📖 Overview
Gaza-Dijkstra is a university project that implements **Dijkstra’s shortest path algorithm** to solve routing problems. It models cities and roads as a graph, then computes the shortest path between two points. This project was developed to strengthen understanding of algorithms, data structures, and practical applications of graph theory.

---

## ✨ Features
- **Graph Representation** – Nodes represent locations, edges represent roads with weights (distance/cost).  
- **Shortest Path Calculation** – Efficiently finds the most optimal route using Dijkstra’s algorithm.  
- **Custom Input** – Users can define their own graph structure and run queries.  
- **Visualization Support** – Displays paths and distances for better comprehension.  
- **Educational Focus** – Designed to help students and learners grasp algorithmic concepts.  

---

## 🛠️ Technologies Used
- **Language:** Java  
- **IDE:** Eclipse  
- **Core Concepts:** Graphs, Priority Queues, Dijkstra’s Algorithm
